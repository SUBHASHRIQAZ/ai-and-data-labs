# Project overview

Each top-level folder is a separate Python project (e.g. `ridepulse-databricks/`) with
its own `tests/` and its own `requirements.txt` or `tests/requirements.txt`. Work inside
the project the issue is about.

`ai-pr-agents/` is this automation. Leave it alone unless the issue is about it.

Don't commit data: `*.csv`, `*.parquet`, `data/`, streaming `checkpoints/`.
